# 方块小镇 · 4-6 岁数学小游戏

给 4-6 岁小朋友学数数、写数字、加减法的网页小游戏。纯静态页面（HTML + CSS + JS），不需要安装、不需要服务器，手机、平板、电脑的浏览器里直接打开。

灵感来自 *Numberblocks* 的“数是有形状的”这一思路，画面、角色和代码都是原创。

## 怎么玩

- 双击 `index.html` 就能打开（或用任意静态服务器，例如 `python -m http.server`，再访问 `http://localhost:8000`）。
- 第一次输入小朋友的名字。**请打开声音**：题目会用普通话朗读，不认字也能玩。
- 首页有 5 个关卡、11 个小游戏。顶部的橙色卡片是“今天推荐”（最久没玩的游戏）。
- 每局 5 题，答对得星星，每 5 颗星星换一张贴纸。
- 右上角 👪 是家长页（要先答一道算术题）。

## 游戏列表

| 关卡 | 游戏 | 玩法 | 对应的理论 |
|---|---|---|---|
| 1 认识方块小人 | 数数乐 | 一个一个点，边点边读，最后回答“一共几个” | 计数五原则：一一对应、稳定顺序、基数原则 |
| | 闪现点阵 | 点阵只亮 1-3 秒，凭一眼判断有几个 | Subitizing（瞬间识数） |

| 2 描红写数字 | 描红写数字 | 沿笔顺描写，再到听写，最后写两位数 | 具身认知、口诀（1 像铅笔细又长……） |
| 3 合体加法 | 积木合体 | 把两堆方块拖到一起，数出一共几个；高级时找“缺少的加数” | CPA：先具象，后图像，再符号 |

## 教学设计

1. **CPA 递进**：每个概念先操作方块，再看图，最后才出现算式。算式 `3 + 2 = 5` 要到 2 级以后、并且在答对之后才显示。
2. **自适应难度**（最近发展区）：每个游戏有 1-4 级。连续 3 次“第一次就答对”升一级，连续 2 次没答对降一级，升降级时只用轻柔的提示。
3. **脚手架，不惩罚**：第一次点错会晃一下并读“再想一想”；第二次点错则亮出正确答案、演示做法，然后下一题。没有红叉、没有扣分。
4. **听为主，少用字**：所有题目由 Web Speech 朗读（普通话，数量读“两个”而不是“二个”）。
5. **多通道反馈**：看（颜色、方块）、听（读数、音效）、动（点、拖、描）同时用。
6. **短局 + 休息提醒**：每局 5 题约 2-3 分钟；当天累计超过设定时间（默认 15 分钟）后，结算页会提示休息，不再显示“再玩一次”。
7. **家长看板**：今天时长、近 7 天趋势、各游戏等级与一次答对率、常错的题（如 `7-4`、`写8`）、一条小建议。

## 项目结构

```
index.html               入口
css/style.css
js/core/logic.js         纯逻辑：出题器、自适应、描红笔画数据与判定器（Node 里可测）
js/core/store.js         本地存储（localStorage）：进度、等级、统计、贴纸、设置
js/core/audio.js         朗读（Web Speech）+ WebAudio 合成音效，无需音频文件
js/core/blocks.js        方块塔 / 点阵 / 手指 / 硬币的 SVG 绘制
js/core/ui.js            DOM 小工具、选择题按钮、庆祝动画
js/core/session.js       一局 5 题的流程、反馈、自适应、结算
js/games/*.js            各游戏，只需实现 round(level, api)
js/pages/home.js         欢迎页、首页（小镇地图）、贴纸册
js/pages/parent.js       家长页
js/app.js                路由（#/、#/play/<id>、#/stickers、#/parent）
tests/                   单元测试和浏览器冒烟测试
```

### 新增一个游戏

在 `js/games/` 新建文件，注册并实现 `round`，再在 `index.html` 里加一行 `<script>`：

```js
NG.registerGame({
  id: 'myGame', stage: 3, icon: '🎲', title: '我的游戏', blurb: '一句话说明',
  round(level, api) {
    api.prompt('题目文字');                 // 显示并朗读
    // ……画出题目；答对调用 api.right({say: '朗读内容'})，
    // 答错调用 api.wrong({key: '易错点标记', reveal: () => { /* 演示正确做法 */ }})
  }
});
```

难度分级、星星、贴纸、统计、家长页都会自动接上。选择题可直接用 `NG.ui.choices(api, options, answer, {...})`。

## 测试

```powershell
node tests/test_logic.js                      # 纯逻辑：出题不变量、自适应、描红判定、存储
powershell -NoProfile -File tests\run_smoke.ps1   # 用无头 Edge 跑完整浏览器流程
powershell -NoProfile -File tests\run_smoke.ps1 -Width 320   # 模拟更窄的手机屏
```

冒烟测试会让“机器人”把每个游戏的每一级都玩一遍（答对路径和连续答错路径）、写出每个数字、跑完整的 5 题会话，并检查在 360px 宽度下没有横向溢出。

## 数据与隐私

学习记录只保存在当前浏览器的 localStorage，不联网、不上传。换设备前，在家长页“备份与换设备”里导出，再到新设备导入。

## 已知限制

- 朗读依赖系统自带的普通话语音。个别浏览器（例如部分微信内置浏览器）可能没有语音，此时只有画面和音效；可以换用系统浏览器打开。
- 描红的判定按“起点 + 沿路线依次经过”来做，容忍度适合幼儿，但不是手写识别。
- 数字范围目前以 0-10 为主，十格框、描红和挑战里涉及到 20。
