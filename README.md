# 数学小游戏

给小朋友学数数、写数字、加减法的网页小游戏。打开网页就能玩，不用安装，手机、平板、电脑的浏览器都可以。

**在线玩：https://alexlee-xz.github.io/123_game/**

灵感来自 *Numberblocks* 的“数是有形状的”这一思路，画面和角色都是原创。

## 怎么玩

1. 用浏览器打开上面的网址。手机和平板可以“添加到主屏幕”，下次像 App 一样点开。
2. 第一次输入小朋友的名字。**请打开声音**：题目会用普通话朗读，不认识字也能玩。
3. 首页有 6 个关卡、14 个小游戏。顶部的橙色卡片是“今天推荐”（最久没玩的游戏），点它就行。
4. 每局 5 题，答对得星星，每 5 颗星星换一张贴纸，贴纸收在 🏅 贴纸册里。
5. 右上角 👪 是家长页（要先答一道算术题，防止孩子误点）。

## 孩子玩起来是什么感觉

- **先摆方块，再看算式**：每个概念先动手摆、再看图，最后才出现算式。`3 + 2 = 5` 要到 2 级以后、答对之后才显示。
- **难度自动调整**：每个游戏有 1-4 级。连续 3 次“第一次就答对”升一级，连续 2 次没答对降一级，升降级时只有轻柔的提示。
- **答错不惩罚**：第一次点错，方块会晃一下，并说“再想一想”；第二次还错，就亮出正确答案、演示做法，然后下一题。没有红叉，也不扣分。
- **听为主，少用字**：题目都会朗读，数量读“两个”而不是“二个”。
- **短局 + 休息提醒**：每局 5 题，约 2-3 分钟。当天玩得超过设定时间（默认 15 分钟），结算页会提醒休息，不再出现“再玩一次”。

## 家长页

点首页右上角 👪，答对算术题后进入：

- **学习概况**：今天玩了多久、累计答题数、一次答对率、星星和贴纸数量
- **最近 7 天**：每天的游戏时长
- **各游戏掌握情况**：当前等级、题数、一次答对率
- **常错的题**：例如 `7-4`、`写8`，还有一条小建议（比如拿真实的积木、水果陪孩子摆一摆）
- **设置**：小朋友的名字、每天玩多久后提醒休息（10 / 15 / 20 / 30 分钟，或不提醒）、声音和朗读开关
- **云同步**、**备份与换设备**、**清空全部记录**（见下文）

## 换设备、多台设备一起玩

学习记录默认只保存在**当前这个浏览器**里，不联网、不上传。有两种方式带到别的设备上：

### 方式一：云同步（推荐）

适合家里有平板、手机、电脑，想让进度一直保持一致。

1. 在一台设备上：家长页 → “云同步” → **开启同步（生成新同步码）**。会得到一个 20 位同步码和一条邀请链接。
2. 在另一台设备上：
   - 打开邀请链接，在家长页点“加入”；或者
   - 家长页 → “云同步”里输入同步码，点“加入”；或者
   - 第一次打开游戏时，在欢迎页点“已经在别的设备玩过？”，输入同步码“找回记录”。
3. 之后每台设备会自动同步：玩完几秒内上传，打开页面或切回页面时拉取最新。也可以点“立即同步”。

要点：

- **两边的进度都不会丢**。两台设备各自玩过，合并后每个游戏以最近玩过的一边为准，星星取多的，贴纸取全部，答题记录合在一起。
- **没网也能玩**。改动先存在本机，网络恢复后自动上传。
- **孩子玩的时候不会被打断**，新进度会等回到首页再显示。
- **同步码要保密**：知道同步码的人都能看到和修改这份记录，只分享给家人。
- 不再同步时，点“关闭同步”（本机记录保留），或“删除云端记录”（云端清空，本机不受影响）。
- 在任何一台设备上点“清空全部记录”，所有已同步的设备都会一起清空。

### 方式二：手动备份

家长页 → “备份与换设备”：在旧设备点“导出”，复制出来的文字粘贴到新设备的同一位置，点“导入”。

## 常见问题

**没有声音 / 不读题？**
先看首页和游戏里有没有“🔇 声音关着”的提示，点“打开声音”。再确认设备没有静音，并点一下页面再试（浏览器需要用户操作后才允许发声）。还是没声音时，到家长页的“设置”里点“🔊 试听”，下面会显示是哪里出了问题（比如浏览器没有中文语音）。朗读用的是系统自带的普通话语音，个别浏览器（例如部分微信内置浏览器）没有这个语音，此时只有画面和音效，可以改用系统自带浏览器打开。

**换了浏览器或清除了浏览器数据，进度没了？**
记录存在浏览器里，换浏览器或清除网站数据就看不到了。想避免这种情况，请开启云同步，或定期导出备份。

**描红写数字总判错？**
描红按“从起点出发、沿笔顺依次经过、不走出轨道”来判断，不是手写识别。前两级有灰色轨道：走出轨道时笔迹会停下，出现一个闪动的小圆圈，回到圆圈里才能接着写；当前要写的那一笔会变成浅蓝色。三、四级是听写，笔迹偏出轨道的部分会变成橙色，偏得太多会要求重写。请从数字的起点开始，按笔顺一笔一笔描，写到终点再抬手。

**数字范围是多少？**
主要是 0-10；十格框、描红和挑战关会用到 20 以内。
